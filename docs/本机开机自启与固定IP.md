# 本机开机自启与固定内网 IP

## 已落地的开机自启方案

项目已经提供以下脚本：

- `scripts/安装开机自启.sh`
- `scripts/卸载开机自启.sh`
- `scripts/查看开机自启状态.sh`

说明：

- 该方案基于 `launchd`
- 会在当前用户登录 macOS 后自动启动项目
- 服务监听 `0.0.0.0:8000`
- 日志输出到 `logs/launchd_service.log`
- 会自动把当前项目同步到运行目录：`~/runzo-web-live`
- `launchd` 实际运行的是 `~/runzo-web-live`，避免触发 `Desktop` 目录的权限限制

如果希望“开机后未登录也自动启动”，需要改成 `LaunchDaemon`，那通常要用 `sudo` 安装到 `/Library/LaunchDaemons/`。

## 推荐固定 IP 方式

推荐优先使用“路由器 DHCP 地址保留”，不要直接在 macOS 里硬改静态 IP。

原因：

- 不容易和 DHCP 地址池冲突
- 换网络后恢复更简单
- 系统 DNS、网关等参数仍由路由器下发

在路由器或公司网管设备里把下面这条绑定上：

- 设备 MAC：`18:4a:53:07:2e:86`
- 保留 IP：`192.168.2.38`

这样这台机器每次连上当前公司网络，都会优先拿到同一个内网 IP。

## 如果必须在 macOS 里手动设固定 IP

只建议在确认 `192.168.2.38` 不会被 DHCP 重新分配时再做。

图形界面路径：

1. 打开“系统设置”
2. 进入“网络”
3. 选择 `Wi-Fi`
4. 点击“详情”
5. 打开 `TCP/IP`
6. 将 `配置 IPv4` 改成“手动”
7. 填入：
   - IPv4 地址：`192.168.2.38`
   - 子网掩码：`255.255.255.0`
   - 路由器：`192.168.2.252`

如果需要命令行方式：

```bash
sudo networksetup -setmanual "Wi-Fi" 192.168.2.38 255.255.255.0 192.168.2.252
```

恢复为 DHCP：

```bash
sudo networksetup -setdhcp "Wi-Fi"
```
