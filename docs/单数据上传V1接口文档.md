# Runzo 单数据上传 v1 接口文档

## 1. 接口说明

- 接口名称：单数据上传 v1
- 接口作用：提供给前端 / App 联调的纯 JSON 协议接口
- 设计目标：
  - 统一使用 `JSON body`
  - `Authorization` 固定走请求头
  - `ts-app-version` 固定走请求头
  - 不依赖当前 Web 页面表单协议
  - 不影响现有网页模块功能

## 2. 接口信息

- 方法：`POST`
- 路径：`/api/runzo/v1/single-upload/execute`
- 请求体类型：`application/json`
- 返回类型：`application/json`

## 3. 请求头

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `Authorization` | string | 是 | Bearer Token |
| `ts-app-version` | string | 是 | App 版本号，例如 `2.6.0` |
| `Content-Type` | string | 是 | 固定为 `application/json` |

补充说明：

- 当前实现兼容 `x-ts-app-version`，但正式对接建议统一使用 `ts-app-version`
- `Authorization` 和 `ts-app-version` 不再从 JSON body 中读取

## 4. 请求体

### 4.1 请求体结构

```json
{
  "environment": "test",
  "userId": "92114529545000186",
  "dailyId": "daily-001",
  "trainingType": "Threshold",
  "runningDistance": 8,
  "trainingBlocks": [
    {
      "minPace": "6:00",
      "maxPace": "6:30",
      "distance": 2
    },
    {
      "minPace": "4:30",
      "maxPace": "4:45",
      "distance": 4
    }
  ],
  "stateDescription": "今天有点累",
  "weekIndex": 1,
  "dayStartTime": 1773676800000,
  "includeDebug": true,
  "userData": {
    "gender": "male",
    "age": 22,
    "weight": 75,
    "height": 175,
    "hrMax": 198,
    "hrRest": 65,
    "targetDistance": 5,
    "intensityPreference": "medium"
  }
}
```

### 4.2 字段说明

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `environment` | string | 否 | 运行环境，默认 `test`，可选：`test` / `preprod` |
| `userId` | string | 是 | 用户 ID |
| `dailyId` | string | 是 | 日计划 ID |
| `trainingType` | string | 是 | 训练类型 |
| `runningDistance` | number | 是 | 跑量距离，必须大于 0 |
| `trainingBlocks` | array<object> | 是 | 训练块数组 |
| `stateDescription` | string | 否 | 自然语言描述调整训练数据强度 |
| `weekIndex` | integer | 否 | 周序号，必须大于 0 |
| `dayStartTime` | integer | 否 | 起始时间戳，必须大于 0 |
| `includeDebug` | boolean | 否 | 是否返回调试信息，默认 `false` |
| `userData` | object | 是 | 用户画像对象 |

### 4.3 `environment` 枚举

| 值 | 说明 |
| --- | --- |
| `test` | 测试环境 |
| `preprod` | 预发布环境 |

### 4.4 `trainingType` 枚举

| 值 | 说明 |
| --- | --- |
| `Easy` | 轻松跑 |
| `LSD` | 长距离慢跑 |
| `Rest` | 休息训练 |
| `ExtraSession` | 额外训练 |
| `Threshold` | 阈值训练 |
| `Interval` | 间歇训练 |

### 4.5 `userData` 字段

| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `gender` | string | 是 | 性别 |
| `age` | integer | 是 | 年龄，必须大于 0 |
| `weight` | number | 是 | 体重，必须大于 0 |
| `height` | number | 是 | 身高，必须大于 0 |
| `hrMax` | integer | 是 | 最大心率，必须大于 0 |
| `hrRest` | integer | 是 | 静息心率，必须大于 0 |
| `targetDistance` | number | 是 | 用户目标距离，必须大于 0 |
| `intensityPreference` | string | 是 | 强度偏好，例如 `low` / `medium` / `high` |

## 5. trainingBlocks 说明

当前 v1 接口不再使用网页里的扁平字段，例如：

- `easyMinPace`
- `thresholdWarmupMinPace`
- `intervalBlock1MinPace`

前端直接传最终 `trainingBlocks`。

### 5.1 Easy / LSD / Rest / ExtraSession

```json
[
  {
    "minPace": "6:00",
    "maxPace": "6:30"
  }
]
```

### 5.2 Threshold

```json
[
  {
    "minPace": "6:00",
    "maxPace": "6:30",
    "distance": 2
  },
  {
    "minPace": "4:30",
    "maxPace": "4:45",
    "distance": 4
  }
]
```

### 5.3 Interval

```json
[

    "distance": 0.5,
    "minPace": "7:20",

  },
  {
    "repeatNum": 3,

    "intervalMaxPace": "5:40",
    "joggingDistance": 0.2,
    "joggingMinPace": "7:20",
    "joggingMaxPace": "7:50"
  }
```

## 6. 成功返回

HTTP 状态码：`200`

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "success": true,
    "executionStatus": "success",
    "summary": "单数据上传执行成功。",
    "environment": "test",
    "debugInfo": {
      "simulateRequest": {},
      "simulateResponse": {},
      "settlementRequest": {},
      "settlementResponse": {}
    }
  }
}
```

### 6.1 返回字段说明

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `code` | integer | 业务码，成功固定 `0` |
| `message` | string | 成功固定为 `success` |
| `data.success` | boolean | 是否成功 |
| `data.executionStatus` | string | 执行状态，成功为 `success` |
| `data.summary` | string | 执行摘要 |
| `data.environment` | string | 当前环境，`test` / `preprod` |
| `data.errorMessage` | string \| null | 错误信息 |
| `data.debugInfo` | object | 调试信息，仅 `includeDebug=true` 时返回 |

## 7. 失败返回

## 7.1 参数校验失败

HTTP 状态码：`400`

```json
{
  "code": 4001,
  "message": "请求头 Authorization 不能为空。",
  "data": null
}
```

## 7.2 业务执行失败

HTTP 状态码：`400`

```json
{
  "code": 4002,
  "message": "execution failed",
  "data": {
    "success": false,
    "executionStatus": "failed",
    "summary": "单数据上传执行失败。",
    "environment": "preprod",
    "errorMessage": "simulate 接口失败（500）：boom"
  }
}
```

## 7.3 服务内部异常

HTTP 状态码：`500`

```json
{
  "code": 5000,
  "message": "服务内部异常。",
  "data": null
}
```

## 8. 调试信息说明

当请求体中 `includeDebug=true` 时，返回体中会带：

```json
{
  "debugInfo": {
    "simulateRequest": {},
    "simulateResponse": {},
    "settlementRequest": {},
    "settlementResponse": {}
  }
}
```

字段说明：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `simulateRequest` | object | simulate 请求体 |
| `simulateResponse` | object \| null | simulate 响应体 |
| `settlementRequest` | object \| null | watch-settle 请求体 |
| `settlementResponse` | object \| null | watch-settle 响应体 |

如果 `includeDebug=false`，则不返回 `debugInfo`。

## 9. 当前实现注意点

- 这是新加的纯 JSON 协议接口
- 现有网页仍然继续使用旧接口：
  - `/api/runzo/single-upload/execute`
- 两套接口并存，互不影响
- v1 接口就是给前端 / App 联调用的，不依赖 HTMX，也不依赖页面表单
